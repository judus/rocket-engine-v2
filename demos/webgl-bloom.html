Reading the metrics

FPS, frame intervals and CPU times come from Rocket’s rolling half-second monitor. Peak is the longest frame interval in that window. Frame jitter is the standard deviation of those intervals; lower means more even pacing. A very short minimum alongside a much longer peak indicates callbacks arriving in bursts. CPU timings measure JavaScript work; they do not measure GPU execution or browser compositing. GPU draw average and peak cover the last 32 valid asynchronous timer-query samples of the scene and enabled post-process passes. Results arrive on later frames; a maximum of four queries can be pending. Invalid (disjoint) samples are discarded. Unsupported browsers show “unsupported” rather than an estimated GPU time. These measurements exclude display latency and compositing; CPU and GPU times overlap and must not be added together.

For comparisons, keep the same canvas size, display scale, camera pose and field of view, and keep this tab in the foreground. FPS is capped by the browser/display refresh rate; CPU times can increase before FPS drops. Recreate demo starts a fresh measurement window.

The left bars are bright white/cyan/amber; the right tile is dim and should stay below the default threshold. The center uses the existing instrument art. An opaque foreground strip blocks part of the display before bloom is extracted. Bloom spreads across image edges; it does not light the surrounding geometry.

Starting…

This bounded milestone uses an opaque RGBA8 scene and two half-resolution RGBA8 scratch targets. Brightness extraction, blur and addition operate in linear color; the final output is sRGB. Existing scene highlights are already clipped: no HDR, tone mapping or exposure yet. Deep halos can show 8-bit quantization. The offscreen scene has depth but no multisample antialiasing in this slice. Radius controls Gaussian sample spacing in half-resolution texels; it is not a physical lens size.

GPU timing covers the scene and all post-process passes. Readback diagnostics run separately and can stall the GPU. Size changes replace framebuffer storage; context restoration and recreation rebuild context-local resources.
