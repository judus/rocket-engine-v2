The original character sprites.

Six archived SzadiArt character sheets, each shown by two independent players. Click a character in either view or select its name. Change the selected player's activity and direction; right mirrors the left-facing side frames. Cyan marks each feet pivot; green highlights your selection.

This is an animation gallery: characters stay in place. WASD movement is the next milestone. Only the original idle/walk clips are used; there is no separate run animation. Both views render the same players, with one scene update per player.
