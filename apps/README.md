# Rocket helper applications

Helper applications live here; rendering experiments remain in `examples/` and playable games in `games/`.

- [Flight Foundry](flight-foundry/README.md): HTML/CSS instrument bench for isolated ship-system experiments.

Run `npm run start` from the repository root, then open <http://localhost:8092/apps/>. Application TypeScript builds to `dist/apps/` through the normal toolchain. No separate bundler, framework or dependency installation is needed.
