Reading the metrics

FPS, frame intervals and CPU times come from Rocket’s rolling half-second monitor. Peak is the longest frame interval in that window. Frame jitter is the standard deviation of those intervals; lower means more even pacing. A very short minimum alongside a much longer peak indicates callbacks arriving in bursts. CPU timings measure JavaScript work; they do not measure GPU execution or browser compositing. GPU draw average and peak cover the last 32 valid asynchronous timer-query samples of the clear and triangle draw. Results arrive on later frames; a maximum of four queries can be pending. Invalid (disjoint) samples are discarded. Unsupported browsers show “unsupported” rather than an estimated GPU time. These measurements exclude display latency and compositing; CPU and GPU times overlap and must not be added together.

For comparisons, keep the same canvas size, display scale, camera pose and field of view, and keep this tab in the foreground. FPS is capped by the browser/display refresh rate; CPU times can increase before FPS drops. Recreate demo starts a fresh measurement window.

100% uses the viewport size × device pixel ratio. Lower the scale for speed; raise it for supersampling. The viewport stays the same size. GPU dimension limits are reported above; shadow-map and instrument-texture sizes remain independent.

Click the canvas to focus. WASD moves, Q / E lowers / raises, Shift speeds up. Drag or use the arrow keys to turn; R returns to the pilot seat. One grid square = one unit; the reference spans 60 × 60 units.

Move with cockpit keeps you in the pilot seat. Turn it off to look around independently; Inspect exterior resets the cockpit at the origin. This is direct navigation, without flight physics or collision.

Render CPU measures JavaScript submission time, not GPU execution. Pixel readback can stall the GPU; use the diagnostic separately from performance comparisons. This small scene verifies correctness; it is not a stress benchmark.

Context-loss testing releases the drawing context temporarily; restore rebuilds programs, mesh buffers, textures and samplers. Recreate retires the previous canvas and GPU resources. No WebGL1 or Canvas fallback is silently substituted.
